J. CLOTHING STORE REDESIGN

Files:
- index.html: premium country/region entry page
- shop.html: responsive storefront homepage
- style.css: all layout, typography, responsive styling
- script.js: mobile menu, search panel, quick-add demo, newsletter demo

HOW TO RUN:
1. Extract the ZIP.
2. Keep all four files in the same folder.
3. Open index.html in your browser.
4. Select a region and click ENTER STORE.

IMPORTANT:
- The photos are remote Unsplash images and need an internet connection.
- Replace the demo photos with your own licensed product photographs before publishing.
- The cart counter and newsletter message are front-end demonstrations only. They do not process orders or save email addresses.
- Connect payment, product inventory, login, shipping and newsletter services before using this as a real online store.
- The design uses the J. name as a visual concept. Make sure you have permission to use any brand name, logo, images or other protected assets.
